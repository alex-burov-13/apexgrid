# Сценарий защиты ApexGrid

## Подготовка

```bash
docker compose up --build
```

Открыть <http://localhost:8000> и заранее создать администратора при необходимости:

```bash
docker compose exec web python manage.py createsuperuser
```

## Демонстрация — 4–5 минут

### 1. Главная — 40 секунд

Показать ближайший этап, countdown, реальный контур трассы, а ниже — все 23 этапа с флагами стран. Сказать: «Страница собирается Django из SQLite, поэтому работает даже без интернета».

### 2. Календарь — 45 секунд

Открыть «Календарь», переключить «Все» → «Sprint», затем grid/list. Обновить страницу: выбранный вид сохранился в Django session.

### 3. Grand Prix и схема трассы — 60 секунд

Открыть карточку этапа. Показать три цветных сектора, направление, клетчатую стартовую линию и технические параметры. Ниже пройти расписание сверху вниз: дни сгруппированы, а Race всегда завершает хронологию. Объяснить: один SVG path переиспользуется в нескольких слоях и не требует WebGL.

### 4. Время и избранное — 35 секунд

Переключить UTC/Москва в header и показать изменившиеся подписи сессий. Добавить этап в избранное и обновить страницу. Аккаунта нет: состояние хранится в session.

### 5. Чемпионат — 30 секунд

Открыть standings пилотов и команд. Показать реальные локальные логотипы: они работают без внешнего CDN. Названия команд, пилотов и Grand Prix сохраняются в оригинале, интерфейс остаётся русским.

### 6. Admin sync — 45 секунд

Открыть `/admin/` → «Обновить F1 2026». Обратить внимание на отдельную confirmation-страницу и последний `SyncRun`. Синхронизация происходит только POST-запросом с CSRF и атомарно: при ошибке локальный snapshot остаётся целым.

### 7. Docker и тесты — 30 секунд

Показать `docker compose ps` со статусом healthy и назвать проверки: unit/integration, browser smoke с настоящим Chrome, production static и Docker smoke.

## Частые вопросы

**Почему Django?** Модели, migrations, sessions и admin закрывают серверную часть единым согласованным стеком.

**Почему SQLite?** Для автономного учебного приложения она даёт переносимую БД одним файлом. Путь вынесен в environment, Docker volume сохраняет изменения.

**Что происходит без интернета?** Все публичные страницы работают. Недоступна только ручная загрузка свежей статистики.

**Почему трасса хранится как SVG path?** Один векторный контур лёгкий, масштабируется без потери качества и переиспользуется в карточках и подробной секторной схеме.

**Как защищены данные при sync?** Полный ответ сначала скачивается и валидируется; запись выполняется внутри `transaction.atomic()`.
